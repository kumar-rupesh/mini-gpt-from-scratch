# Mini GPT from Scratch

Building a small GPT-like language model from scratch while learning Python, Mathematics, PyTorch, Deep Learning, and LLM Engineering.

## 🎯 Project Objective

The goal of this project is to understand how Large Language Models work internally by implementing a small GPT-like model step by step.

This is an educational project focused on learning the fundamentals of modern language models.

## 🛠️ Technologies

- Python
- NumPy
- PyTorch
- Git & GitHub
